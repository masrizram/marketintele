## Kenapa versi ini lebih kuat

Ada **3 perubahan fundamental** dari prompt lama:

### 1. Bukan lagi remediation-only

Report sebelumnya benar bahwa supplier sourcing, market clearing, demand, competition, EV, decay, dan learning adalah **architectural gaps**, bukan sekadar bug. Prompt baru sekarang **memerintahkan agent untuk membangun gap tersebut**, bukan hanya mencatatnya sebagai `DEFERRED`. IDEA memang mendefinisikan supplier entity resolution, supplier verification, supplier pricing, market clearing price, demand, competition, dan landed cost sebagai bagian sistem inti. 

### 2. Financial engine sekarang benar-benar independen

Ini secara khusus memperbaiki temuan:

```text
Engine A:
selling - (landed + fees)

Engine B:
(selling - fees) - landed
```

yang secara matematis identik.

Prompt baru memaksa **dua calculation path yang berbeda**, bukan sekadar dua fungsi dengan tanda kurung berbeda.

### 3. Ada "vertical slice" rule

Ini penting agar AI coding agent tidak melakukan:

```ts
class SupplierEngine {}
```

lalu mengklaim supplier engine selesai.

Sekarang definition of done memerlukan:

```text
implemented
→ integrated
→ executed
→ tested
→ validated
→ observable
→ failure-handled
→ security-reviewed
→ evidence-traceable
```

Ini jauh lebih sulit untuk "diakali".
